## PH-184: Structure determination methods

Physics Paper II · Physics · Solid state physics

*Goal:* Understand Structure determination methods, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Structure determination methods belongs to Solid state physics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Connect microscopic order to the measurement: lattice plus basis gives structure, reciprocal spacing controls diffraction, and electronic states form bands. State the approximation and temperature regime. Distinguish a material property from the instrument used to infer it.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing structure determination methods. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: Compare two materials/structures illustrating structure determination methods; predict the effect on a measurable electrical, structural or thermal property.

### Worked example

Worked route: identify the requested result in “Derive the main physical relation(s) governing structure determination methods. Define every symbol, state approximations and provide a labelled sketch where useful.”; select the governing principle; state assumptions; carry the algebra without skipping vector directions or boundary conditions; then interpret the result physically. Use the supplied self-check rubric: Assessment: principle and diagram → algebra/derivation → assumptions → units/limiting case.
