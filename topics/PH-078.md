## PH-078: Dielectric sphere boundary value problem

Physics Paper I · Physics · Electrostatics / magnetostatics

*Goal:* Understand Dielectric sphere boundary value problem, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Dielectric sphere boundary value problem belongs to Electrostatics / magnetostatics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Use symmetry before integration. Choose Gauss, Poisson/Laplace, images or multipoles according to geometry and boundary conditions. State which potential and normal-field components are continuous at an interface, and test the far-field behaviour.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing dielectric sphere boundary value problem. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: Choose a solvable symmetry for dielectric sphere boundary value problem, specify boundary conditions and calculate the resulting field or energy.
