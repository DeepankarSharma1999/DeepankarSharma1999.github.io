## PH-139: Particle in 3D box

Physics Paper II · Physics · Quantum mechanics

*Goal:* Understand Particle in 3D box, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Particle in 3D box belongs to Quantum mechanics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Write the state, operator and boundary conditions. Normalize before calculating probabilities or expectation values. Eigenvalues are measurement outcomes; a general state is a superposition. Check Hermiticity, units and limiting behaviour rather than treating a memorized wavefunction as universal.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing particle in 3d box. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: For a well-defined state or potential, show how to compute the observable associated with particle in 3d box using normalized states.
