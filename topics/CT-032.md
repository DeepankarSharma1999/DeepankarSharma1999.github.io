## CT-032: Data sufficiency

Prelims CSAT (qualifying) · CSAT · Reasoning / decision making

*Goal:* Build a reliable method for Data sufficiency and apply it under CSAT time pressure.

### Core mechanism

Data sufficiency is a reasoning / decision making skill. List only the facts that are given, symbolize the constraints, and draw a small table, diagram or Venn set. A valid conclusion must follow in every arrangement allowed by the statements. For decision questions, identify stakeholders, legality, urgency and the least harmful workable action.

### Exam-facing synthesis

Build the topic around three defensible links. Data sufficiency asks whether the supplied statements determine an answer, not whether you can guess one example. Test each statement independently before testing them together. A yes/no question is determined when all permitted cases give the same yes or no result. For objective questions, classify each statement by process, chronology or scope before eliminating it. For a written answer or worked solution, state the governing idea, apply it to a concrete example, and finish with the limitation: Do not combine statements before checking them separately or confuse a unique numerical value with a uniquely determined yes/no answer.
