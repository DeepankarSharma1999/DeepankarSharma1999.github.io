## PH-202: Logic gates and truth tables

Physics Paper II · Physics · Devices and electronics

*Goal:* Understand Logic gates and truth tables, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Logic gates and truth tables belongs to Devices and electronics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Start from the device characteristic and operating region, then build the circuit relation. Mark bias polarity, current direction and reference ground. For logic, write the truth table before simplifying; for amplifiers distinguish voltage gain, power gain, feedback and saturation.

### How to practise it

Use this exact checkpoint: Draw truth tables of NOT, AND, OR, NAND, NOR and XOR, and show universal-gate implementation. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: Construct XOR using only NAND gates; give a valid gate-level design.

### Worked example

Worked route: identify the requested result in “Draw truth tables of NOT, AND, OR, NAND, NOR and XOR, and show universal-gate implementation.”; select the governing principle; state assumptions; carry the algebra without skipping vector directions or boundary conditions; then interpret the result physically. Use the supplied self-check rubric: Assessment: principle and diagram → algebra/derivation → assumptions → units/limiting case.

### Recall

- - **q:** Which governing equation and assumptions control Logic gates and truth tables?
  - **a:** State the equation, define every symbol, name the approximation or boundary condition, and give one limiting case. Then reproduce the first derivation or calculation from the practice tab.

### Common trap

Substituting into a remembered formula before fixing the system, sign convention, approximation and units.
