## PH-044: Paraxial optics and ABCD matrix

Physics Paper I · Physics · Geometrical optics

### Bridge: 2×2 matrices: multiplying, the determinant and why the order matters

**Notation.** A 2×2 matrix is written row by row, with a semicolon between rows: `[ a b ; c d ]` means the first row is a, b and the second row is c, d. A ray is described by a column of two numbers, written `( y , q )`, and the matrix acts on it from the left:

$$ [ a b ; c d ] ( y , q ) = ( a y + b q , c y + d q ) $$

**Product.** To multiply two matrices take each row of the left matrix against each column of the right one:

$$ [ a b ; c d ] [ e f ; g h ] = [ ae + bg   af + bh ; ce + dg   cf + dh ] $$

*Worked check:* `[ 1 0 ; −2 1 ] [ 1 3 ; 0 1 ]` = `[ 1 3 ; −2 −5 ]`. The first row is (1·1 + 0·0, 1·3 + 0·1) = (1, 3); the second is (−2·1 + 1·0, −2·3 + 1·1) = (−2, −5).

**The order matters.** Reverse the two factors: `[ 1 3 ; 0 1 ] [ 1 0 ; −2 1 ]` = `[ −5 3 ; −2 1 ]`, which is a different matrix. In optics the first thing that happens to the ray is written **rightmost**, next to the column, because the matrix nearest the column acts first.

**Determinant.** For `[ a b ; c d ]` the determinant is ad − bc. In the check above, the determinant of `[ 1 0 ; −2 1 ]` is 1·1 − 0·(−2) = 1 and that of `[ 1 3 ; 0 1 ]` is 1. Their product `[ 1 3 ; −2 −5 ]` has determinant (1)(−5) − (3)(−2) = −5 + 6 = 1. This is the rule **det(MN) = det M × det N**: the determinant of a product is the product of the determinants, in either order.

**Why optics wants this.** Each step of a lens system has determinant 1, so the whole system does too, and the determinant checks the arithmetic.

**Beginner traps**

- Multiplying element by element is wrong; it is row by column.
- Writing the matrices in the order the light meets them (left to right) reverses the product.

### Bridge: Ray height, ray angle and small angles in radians

**Describing a ray.** Choose the axis of the optical system (the line through all the centres of the spherical surfaces) and call it the z-axis, with light travelling towards +z, left to right. At any plane perpendicular to the axis a ray is fixed by two numbers: its **height y** above the axis (negative if below) and its **slope α**, the angle the ray makes with the axis, in **radians**, taken positive when the ray is rising (y increasing as z increases).

**Radians.** An angle in radians is arc length divided by radius, so 180° = π rad and 1° = 0.017453 rad. For small angles the sine, the tangent and the angle itself are almost equal: for 5° the sine and the angle differ by about 0.13 percent; module 2 tabulates where this stops being true.

**Why slope turns into height.** A ray of slope α that travels a distance d along the axis changes its height by d × tan α. For a small angle this is d × α, so *the height after travelling is the old height plus d times the slope.* That one sentence is the whole translation matrix.

**Why n times α.** Snell's law is n₁ sin i = n₂ sin r (PH-043 module 5 derives it from Fermat's principle). For small angles it becomes n₁ i = n₂ r. The combination n × (angle) therefore carries straight across a surface. We give it a name, the **optical direction** λ = nα (Brij Lal calls λ the optical direction cosine, Eq. 7.1 on PDF p. 157, which equals μ cos θ for the angle θ measured from the transverse axis; for small α this is nα).

**Beginner traps**

- Using degrees inside a formula that assumes radians.
- Forgetting that a negative height is allowed: a ray below the axis has y < 0.

### 1. Orientation: what the matrix method does, the exam pattern and the plan

*Objective:* State what a system matrix is, name the five verified questions that use it, and choose which modules to read first.

## The idea in one paragraph

A camera lens, a microscope or a telescope has many glass surfaces. To find where it forms an image you could trace a ray surface by surface, treating each image as the next object. Brij Lal and Subrahmanyam (PDF p. 156) call this step-by-step method lengthy and tedious and describe the matrix method as an easier alternative that suits computers. The idea is that, for rays close to the axis, each step (travel through a gap, refract at a surface) changes the ray's height and slope in a **linear** way, so each step is a 2×2 matrix. Multiply the matrices in order and the whole instrument becomes **one** 2×2 matrix, the **system matrix**, written `[ A B ; C D ]` in this lesson.

## What the four numbers tell you

For a system in air on both sides (details in module 4):

- **C** is minus the power of the system: the focal length is F = −1/C.
- **B = 0** is the condition for the plane in front and the plane behind to be *object and image*.
- **A** is then the magnification, and **D** equals 1/A.
- **A and D** also fix where the two principal planes lie (module 7).
- **Determinant AD − BC = 1** always, which checks your arithmetic.

## Why it is examined

The project's verified Paper I list for this topic has five questions (full text in module 10): a 10-mark system matrix of a thin lens with its focal length (2017), a 20-mark thick-lens system matrix with the thin-lens formula (2022), a 10-mark two-thin-lens system matrix with focal length and unit planes (2024, part i), a 10-mark numerical on two convex lenses of 10 cm and 20 cm separated by 25 cm (2024, part ii), and a 15-mark thick-lens system matrix (2025).

### 2. Foundation: the paraxial (Gaussian) approximation and where it fails

*Objective:* State the paraxial approximation, give the size of the error it makes at 5, 10 and 20 degrees, and fix the sign convention used in this lesson.

## The approximation

Brij Lal (PDF p. 159, Eq. 7.14) replaces sin i by i and sin r by r in Snell's law, "in case of paraxial rays". A ray is **paraxial** if (a) it stays close to the axis, so heights are small compared with the radii of curvature, and (b) it makes small angles with the axis. To first order sin x ≈ x, tan x ≈ x and cos x ≈ 1. The optics built on this is **Gaussian optics**; it is exact only in the limit of vanishing angles.

## How big is the error?

Recomputed (the relative error is (x − sin x)/x, the fraction by which the angle exceeds its sine):

| Angle | sin x | Error replacing sin x by x | Error replacing tan x by x |
|---|---|---|---|
| 5° | 0.08716 | 0.13 percent | 0.26 percent |
| 10° | 0.17365 | 0.51 percent | 1.03 percent |
| 14.06° | 0.24287 | 1.00 percent | 2.1 percent |
| 20° | 0.34202 | 2.02 percent | 4.27 percent |
| 30° | 0.50000 | 4.51 percent | 10.3 percent |

So "paraxial" is a good approximation to about 10° and degrades quickly after 20°.

## What failing looks like: spherical aberration

Take a single spherical surface of radius 50 mm separating air from glass of index 1.5, lit by a parallel beam. Module 9 (f₂ = n₂/P) or PH-043 module 7 gives the paraxial focus at 1.5 × 50/(1.5 − 1) = 150 mm from the vertex. Tracing the exact ray at height h (sine law, no approximation) and recomputing:

| Ray height h | Exact axis crossing | Shortfall from 150 mm |
|---|---|---|
| 5 mm | 149.67 mm | 0.33 mm |
| 30 mm | 136.99 mm | 13.01 mm |

Doubling h roughly quadruples the shortfall (0.33 to 1.34 mm), so the error grows as h². Outer rays focus too close: this is **spherical aberration**, the first of the defects the next-order (third-order) theory handles. Matrix methods here describe only the ideal, aberration-free first-order image.

## Sign convention used throughout

Light travels left to right; the z-axis points right. Distances measured to the right of a reference point are positive, to the left negative; heights above the axis are positive; the slope of a ray is positive when it rises to the right; a radius of curvature is positive when the centre of curvature lies to the right of the surface. This is the Cartesian convention of PH-043 module 7 (where a real object has u negative and a convex first surface has R positive).

*Book note:* Chapter 4 (PDF p. 93) uses the opposite angle rule; this lesson follows Chapter 7 (rising ray positive; see the source notes).

## Why linear is enough

Within the approximation every relation between output and input (height and slope) is linear: double the input and you double the output. A linear relation between two numbers and two numbers is exactly what a 2×2 matrix expresses.

### 3. Core: the translation and refraction matrices, and their determinants

*Objective:* Derive the translation matrix and the refraction matrix, state their determinants, and relate the (y, nα) form to the (y, α) form with determinant n₁/n₂.

## Setting up the ray vector

Use the ray vector **( y , nα )**: height first, optical direction second (module 2). The refractive index n is the index of the medium the ray is in at that plane. Matrices multiply this column from the left.

## Translation through a gap

A ray at height y₁ with slope α₁ travels a distance d in a uniform medium of index n (a straight line). Then

$$ y₂ = y₁ + d α₁ = y₁ + (d/n)(n α₁) $$
$$ n α₂ = n α₁   (the slope does not change in a uniform medium) $$

As a matrix:

$$ T = [ 1  d/n ; 0  1 ]   (Brij Lal Eq. 7.11, in the book's ordering) $$

The determinant is 1·1 − (d/n)·0 = **1**. The entry d/n is the *reduced distance* (distance divided by index); in air it is just d.

## Refraction at a spherical surface

A surface of radius R separates index n₁ (left) from n₂ (right); its centre C is at distance R to the right of the vertex if R > 0. A ray meets the surface at small height y with slope α₁ before and α₂ after. The normal at that point is the line from C through the point; its slope is −y/R (it falls as y rises when C is on the right). Angles are differences of slopes, so

$$ i = α₁ + y/R   and   r = α₂ + y/R $$

(Brij Lal writes i = φ + α₁, r = φ + α₂, Eq. 7.15, with φ the angle of the normal.) The paraxial Snell law n₁ i = n₂ r gives

$$ n₁ α₁ + n₁ y/R = n₂ α₂ + n₂ y/R $$
$$ n₂ α₂ = n₁ α₁ − [ (n₂ − n₁)/R ] y $$

Define the **power of the surface** P = (n₂ − n₁)/R (Eq. 7.18; unit: dioptre when R is in metres). The height does not change at the surface (y₂ = y₁). Hence

$$ R_s = [ 1  0 ; −P  1 ] $$

with determinant 1·1 − 0·(−P) = **1**. Check on a plane surface (R → ∞, P = 0): the matrix is the identity, so n₂α₂ = n₁α₁, which is Snell's law and explains why a ray leaving water (n = 1.33) into air is steeper by the factor 1.33 (for small slopes).

## The (y, α) version and the determinant n₁/n₂

Many textbooks use the plain slope α instead of nα: ray vector ( y , α ). Since nα = n × α, the refraction step becomes α₂ = (n₁/n₂) α₁ − [ P/n₂ ] y, i.e.

$$ R_α = [ 1  0 ; −P/n₂   n₁/n₂ ] $$

whose determinant is **n₁/n₂**. The translation matrix is [ 1 d ; 0 1 ], determinant 1. By det(MN) = det M det N a whole system in the (y, α) form has determinant **n_in/n_out**, the ratio of the first to the last index; it is 1 only if the two outer media are the same. In the (y, nα) form the determinant is always 1.

## Dictionary to the book

Brij Lal uses the column ( λ , x ) = ( nα , y ); his [ b −a ; −d c ] corresponds to this lesson's [ A B ; C D ] by A = c, B = −d, C = −a, D = b (table in the master notes).

### 4. Core: the system matrix, the product order and what A, B, C and D mean

*Objective:* Build a system matrix in the correct order, prove its determinant is 1, and read off focal length, the imaging condition B = 0, the magnification and the special cases A = 0, D = 0, C = 0.

## Building the matrix

A ray passes surface 1, a gap, surface 2 and so on. If the matrices are M₁, M₂, …, M_N in the order the light meets them, the system matrix is

$$ M = M_N ⋯ M₂ M₁ $$

with the **first** event **rightmost** (Brij Lal Eq. 7.23, [R₂][T₂₁][R₁] = [S]). Each factor has determinant 1, so det M = 1: **AD − BC = 1**. (In the book's notation this is bc − ad = 1, Eq. 7.31.) Write

$$ M = [ A  B ; C  D ] ,   y_out = A y_in + B (nα)_in ,   (nα)_out = C y_in + D (nα)_in $$

## The meaning of each entry (air on both sides)

**C: power.** Send in a ray parallel to the axis at height y ((nα)_in = 0). It leaves at height A y with optical direction C y, so its slope is C y. It cuts the axis at a distance −A y/(C y) = −A/C beyond the exit vertex. The equivalent focal length is defined from the principal plane (module 7) and equals

$$ F = −1/C ,   power P = −C $$

*Check:* a thin converging lens has C = −1/f < 0, so F = f > 0.

**B = 0: conjugate planes.** Suppose the matrix connects an object plane to an image plane. A point on the axis (y_in = 0) emits rays of every slope; they all reach the image plane at height y_out = B (nα)_in. They meet at one point, whatever their slope, only if **B = 0**. That is the imaging condition (Brij Lal Eq. 7.39).

**A: lateral magnification** when B = 0, because y_out = A y_in (Eq. 7.41). **D: 1/A**, because AD − BC = AD = 1. So D is the *angular* magnification: slopes shrink as heights grow, in agreement with the book's statement that angular and lateral magnification are inversely proportional (Eq. 5.26).

**Special cases.** A = 0: y_out = B (nα)_in, the output position depends only on the input *angle*; the output plane is the back focal plane (position from angle). D = 0: (nα)_out = C y_in, the output angle depends only on the input *position*; the input plane is the front focal plane. C = 0: no focusing power at all (an *afocal* system, as in a telescope).

## The imaging equations

Let the object be at distance s to the left of the first vertex (s > 0, so u = −s) and the image at distance v to the right of the last vertex. The full chain is T(v) M T(s):

$$ M T(s) = [ A   As + B ; C   Cs + D ] $$
$$ T(v) M T(s) = [ A + vC    As + B + v(Cs + D) ; C   Cs + D ] $$

The imaging condition B_total = 0 gives

$$ v = −(As + B)/(Cs + D) ,    m = A_total = A + vC = 1/(Cs + D) $$

(m follows from A_total D_total = 1 once B_total = 0.) These agree with the book's Eq. 7.39 and 7.43 under the dictionary of module 3: put A = c, B = −d, C = −a, D = b and D₁ = −s in bD₂ + aD₁D₂ − cD₁ − d = 0.

**Dimensions:** A and D are numbers; B is a length; C is 1/length.

### 5. Core: the thin lens matrix and the lens formula (the 2017 question)

*Objective:* Derive the thin lens matrix, compute the system matrix and focal length of a biconvex lens of radius 50 cm and index 1.5, and derive the lens formula from the matrix.

## Matrix of a thin lens

A lens in air has two surfaces: air to glass of radius R₁, then glass to air of radius R₂. The surface powers are

$$ P₁ = (μ − 1)/R₁ ,    P₂ = (1 − μ)/R₂ = −(μ − 1)/R₂ $$

The matrix of the lens is R₂ · T · R₁. For a **thin** lens the thickness t is negligible, so T = [ 1 0 ; 0 1 ] and (module 1 of the bridge, the product rule)

$$ M = [ 1 0 ; −P₂ 1 ] [ 1 0 ; −P₁ 1 ] = [ 1  0 ; −(P₁ + P₂)  1 ] $$

Hence C = −(P₁ + P₂), so the focal length is

$$ 1/f = P₁ + P₂ = (μ − 1)(1/R₁ − 1/R₂) $$

the lens-maker's formula (Brij Lal Eq. 7.51), the same result PH-043 module 8 obtains from equal optical paths. Powers of thin lenses placed in contact add, because their matrices are of this form: `[ 1 0 ; −P₂ 1 ] [ 1 0 ; −P₁ 1 ] = [ 1 0 ; −(P₁+P₂) 1 ]`.

## The 2017 question: R = 50 cm each, μ = 1.5

The wording says "radius of curvature 50 cm each". The book's Example 7.1 and Problem 1 treat this as a double convex lens (R₁ = +50 cm, R₂ = −50 cm), which is the reading used here. (If both radii were +50 cm, the same centre side, P₁ + P₂ would be zero and there would be no focusing.)

- P₁ = 0.5/50 = 0.01 cm⁻¹; P₂ = −0.5/(−50) = 0.01 cm⁻¹.
- P = 0.02 cm⁻¹ = 2 dioptres (with 50 cm = 0.5 m).

$$ M = [ 1  0 ; −0.02  1 ] $$

The determinant is 1. Then C = −0.02 cm⁻¹, so **f = 1/0.02 = 50 cm**. In the book's ordering the same lens is [ 1 −0.02 ; 0 1 ] (Example 7.1).

## The lens formula from the matrix

Use module 4 with A = 1, B = 0, C = −P, D = 1. The image condition As + B + v(Cs + D) = 0 reads

$$ s + v (1 − P s) = 0 $$

Divide by s v: 1/v + 1/s − P = 0, so 1/v = P − 1/s. With the sign convention u = −s:

$$ 1/v − 1/u = P = 1/f $$

This is the thin-lens formula (Eq. 7.50, 7.51). The magnification is m = 1/(Cs + D) = 1/(1 − Ps). Multiply 1/v = P − 1/s by s to get s/v = Ps − 1, so 1 − Ps = −s/v and m = −v/s = v/u. This is the familiar m = v/u.

**Beginner trap:** the thin-lens matrix is *not* [ 1 0 ; −P 1 ] with P the power of one surface; P is the **sum** of both surface powers.

### 6. Core: the thick lens matrix and the thin-lens limit (the 2022 and 2025 questions)

*Objective:* Derive the system matrix of a thick lens of thickness t, index μ and radii R₁, R₂, check its determinant, find its focal length, and recover the thin-lens formula as t tends to zero.

## Setting up

Light meets three things in order: refraction at the first surface (power P₁ = (μ − 1)/R₁), travel through glass for a distance t (reduced distance t/μ), and refraction at the second surface (power P₂ = (1 − μ)/R₂ = −(μ − 1)/R₂). The system matrix is

$$ M = R₂ T R₁ = [ 1 0 ; −P₂ 1 ] [ 1 t/μ ; 0 1 ] [ 1 0 ; −P₁ 1 ] $$

## Multiplying, step by step

First T·R₁ (the two right-hand factors):

$$ T R₁ = [ 1 − P₁ t/μ    t/μ ; −P₁    1 ] $$

(row 1: 1·1 + (t/μ)(−P₁) and 1·0 + (t/μ)·1; row 2: 0·1 + 1·(−P₁) and 1.) Then left-multiply by R₂:

$$ M = [ 1 − P₁ t/μ    t/μ ;  −P₁ − P₂ (1 − P₁ t/μ)    1 − P₂ t/μ ] $$

(row 2, first entry: −P₂(1 − P₁t/μ) + 1·(−P₁); second entry: −P₂(t/μ) + 1.) So

$$ A = 1 − P₁ t/μ ,   B = t/μ ,   C = −( P₁ + P₂ − P₁ P₂ t/μ ) ,   D = 1 − P₂ t/μ $$

(Brij Lal Eqs. 7.46 and 7.30a to 7.30d, in his ordering.)

**Determinant check.** AD − BC = (1 − P₁t/μ)(1 − P₂t/μ) + (t/μ)(P₁ + P₂ − P₁P₂t/μ). Expanding, the P₁t/μ and P₂t/μ terms cancel against each other and the P₁P₂t²/μ² terms cancel, leaving **1**.

## In terms of R₁ and R₂

The power of the lens is P = −C = P₁ + P₂ − P₁P₂ t/μ. Substitute P₁ = (μ−1)/R₁, P₂ = −(μ−1)/R₂:

$$ 1/F = (μ − 1) [ 1/R₁ − 1/R₂ + (μ − 1) t / (μ R₁ R₂) ] $$

which is Brij Lal Eq. 7.48. The 2025 question (15 marks) asks only for the matrix; the 2022 question (20 marks) asks for the matrix and the thin-lens formula.

## The thin-lens limit (the second half of the 2022 question)

Let t → 0. Then A = D = 1, B = 0, and C = −(P₁ + P₂), so M becomes the thin-lens matrix of module 5, and the bracket in the focal length loses its last term: 1/f = (μ−1)(1/R₁ − 1/R₂). Using module 4 with A = D = 1, B = 0, C = −P gives 1/v − 1/u = P = 1/f, the thin-lens formula. Writing these two steps (matrix limit, then B = 0) is a complete derivation.

## Numbers: the book's Example 7.3 (recomputed)

μ = 1.6, R₁ = +6 cm, R₂ = −6 cm, t = 2 cm. P₁ = 0.6/6 = 0.1 cm⁻¹, P₂ = −0.6/(−6) = 0.1 cm⁻¹, t/μ = 1.25 cm.

A = D = 0.875, B = 1.25 cm, C = −0.1875 cm⁻¹, determinant 0.765625 + 0.234375 = 1 ✓, so F = 5.333 cm against 5 cm for the thin lens (about 6.7 percent longer).

**Beginner traps:** using t instead of t/μ in the translation matrix; writing P₂ with the wrong sign (for a biconvex lens R₂ is negative, so P₂ is positive).

### 7. Core: principal planes, focal points and nodal points from the matrix elements

*Objective:* Show that any system matrix in air equals travel, a thin lens of focal length F, travel; read F, the plane positions α and β, and the focal points from A, C and D; and derive the Gauss formula measured from the principal planes.

## What a principal plane is

Brij Lal (PDF pp. 109 to 110) defines the **second principal plane** as the plane where an incident ray parallel to the axis, extended forward, meets the emergent ray extended backward; the refraction can be imagined to happen there at one stroke. The first principal plane is found in the same way for the reversed ray. The two planes are **conjugate with magnification +1** (unit planes): a ray entering the first at some height leaves the second at the same height. They need not lie inside the instrument (Gauss, 1841, PDF p. 109).

## A matrix as travel + thin lens + travel

Let H₁ be α to the right of the first vertex V₁ and H₂ be β to the right of the last vertex V₂ (β is negative if H₂ lies to the left of V₂). The ray goes V₁ to H₁ (distance α), is refracted by a thin lens of focal length F placed at the planes, then goes from H₂ back to V₂ (distance −β, because H₂ lies before V₂ when β < 0):

$$ M = T(−β) L T(α)    where   L = [ 1 0 ; −1/F 1 ] ,   T(x) = [ 1 x ; 0 1 ] $$

Multiply: L T(α) = [ 1  α ; −1/F  1 − α/F ]. Then T(−β) = [ 1 −β ; 0 1 ] times this gives

$$ M = [ 1 + β/F    α − β + αβ/F ;  −1/F    1 − α/F ] $$

Compare with [ A B ; C D ]:

$$ C = −1/F ,   A = 1 + β/F ,   D = 1 − α/F $$

Solving, with F = −1/C:

$$ F = −1/C ,    α = (D − 1)/C ,    β = (1 − A)/C $$

These are Brij Lal's α = (1 − b)/a and β = (c − 1)/a (Eqs. 7.52, 7.53) under the dictionary A = c, D = b, C = −a. The entry B = α − β + αβ/F then follows from AD − BC = 1 (derivation D4).

**Focal points.** The second focal point lies F beyond H₂, so its distance from V₂ is F + β = F·A (the back focal distance −A/C of module 4). The first lies F before H₁, at α − F = −F·D from V₁.

**Nodal points** coincide with the principal points when the end media are the same (Brij Lal PDF p. 112, §5.2.3.3, and PDF p. 170, §7.10.3); module 9 treats different media.

## The Gauss formula from the principal planes

Put the object at u (negative) from H₁ and the image at v from H₂. Distances from the vertices are then s = −u − α (to the left) and v + β (to the right). The chain T(v + β) M T(s) = T(v + β) T(−β) L T(α) T(s) = T(v) L T(−u) because the translations add. Its B entry is −u + v(1 + u/F), which must vanish:

$$ 1/v − 1/u = 1/F $$

So the thin-lens formula is true for any system **provided the distances are measured from the principal planes** (Brij Lal Eq. 7.59, 5.19). That is the whole point of principal planes.

## Worked example (recomputed): the equi-convex lens of Problem 4

μ = 1.5, R = ±4 cm, t = 1 cm gives A = D = 0.91667, C = −0.23958 cm⁻¹, so F = 4.174 cm, α = +0.348 cm, β = −0.348 cm and back focal distance F·A = 3.826 cm (the book rounds to 4.2 and 0.35 cm; the full matrix is in practice numerical N3). The estimate α ≈ t/(2μ) = 0.333 cm (Eq. 7.62) is about 4 percent below the exact 0.348 cm.

**Beginner trap:** using the Gauss formula with distances measured from the vertices; it needs the principal planes.

### 8. Core: two thin lenses, the focal length and the unit planes (the 2024 questions)

*Objective:* Derive the system matrix of two thin lenses separated by d, the combined focal length and the plane positions, and solve the f₁ = 10 cm, f₂ = 20 cm, d = 25 cm numerical.

## The matrix

Lens 1 of focal length f₁, a gap d in air, lens 2 of focal length f₂. In order, with lens 1 acting first:

$$ M = L₂ T(d) L₁ = [ 1 0 ; −1/f₂ 1 ] [ 1 d ; 0 1 ] [ 1 0 ; −1/f₁ 1 ] $$

Step 1: T L₁ = [ 1 − d/f₁    d ; −1/f₁    1 ].
Step 2: L₂ times that:

$$ M = [ 1 − d/f₁    d ;  −1/f₁ − (1/f₂)(1 − d/f₁)    1 − d/f₂ ] $$

so

$$ A = 1 − d/f₁ ,   B = d ,   C = −( 1/f₁ + 1/f₂ − d/(f₁ f₂) ) ,   D = 1 − d/f₂ $$

Brij Lal's Eq. 7.70 has the same entries. Determinant: AD − BC = (1 − d/f₁)(1 − d/f₂) + d(1/f₁ + 1/f₂ − d/(f₁f₂)) = 1 − d/f₁ − d/f₂ + d²/(f₁f₂) + d/f₁ + d/f₂ − d²/(f₁f₂) = 1 ✓.

## Focal length and planes

From module 7, F = −1/C:

$$ 1/F = 1/f₁ + 1/f₂ − d/(f₁ f₂) = (f₁ + f₂ − d)/(f₁ f₂) ,   F = f₁ f₂ /(f₁ + f₂ − d) $$

$$ α = (D − 1)/C = F d / f₂ ,    β = (1 − A)/C = −F d / f₁ $$

(Brij Lal Eqs. 7.71 to 7.73; α is measured from lens 1, β from lens 2.) Special cases: d = 0 gives 1/F = 1/f₁ + 1/f₂ (powers add) and α = β = 0; d = f₁ + f₂ gives C = 0, an afocal pair (telescope); d > f₁ + f₂ gives F < 0. The optical interval Δ = d − f₁ − f₂ gives F = −f₁f₂/Δ (PDF p. 103, Eq. 4.32).

### 9. Master: different media on the two sides, nodal points and the n₁/n₂ determinant

*Objective:* State how the focal lengths, principal planes and nodal points change when the first and last media have different indices, and check the rules on a single surface and on a lens with air on one side and water on the other.

## What changes

Everything so far assumed air at both ends. Let the first medium have index n₁ and the last n₂, and keep the ray vector ( y , nα ), whose matrices all have determinant 1 (module 3). The same chain of matrices gives [ A B ; C D ], but the optical meaning changes:

- The **power** is still P = −C.
- There are now two different focal lengths, measured from their principal planes: **f₁ = −n₁/P** (object side, negative for a converging system) and **f₂ = n₂/P** (image side). Their ratio is f₁/f₂ = −n₁/n₂.
- The principal planes are found as before from unit magnification but with the indices included: **α = n₁(D − 1)/C** from the first vertex and **β = n₂(1 − A)/C** from the last vertex. For n₁ = n₂ = 1 these reduce to module 7.
- The **nodal points** (a ray entering at the first emerges from the second parallel to itself) are at **g = (n₁D − n₂)/C** from the first vertex and **h = (n₁ − n₂A)/C** from the last vertex. Derivation: start a ray at the axial point N₁ with slope α₁, so ( 0 , n₁α₁ ). Travelling back to V₁ and applying M, the output direction is n₁α₁ (D − Cg/n₁) and this must equal n₂α₁ (the same angle α₁ in the last medium). Hence D − Cg/n₁ = n₂/n₁, i.e. g = (n₁D − n₂)/C. The condition that the ray reaches the axis at N₂ gives h in the same way.
- When n₁ ≠ n₂ the nodal points do **not** coincide with the principal points: N₁ − H₁ = f₁ + f₂ (Brij Lal PDF p. 113 states P₁N₁ = f₁ + f₂, zero in air because f₂ = −f₁).

### Notes: Definitions

- Paraxial ray: a ray close to the axis and at a small angle, for which sin x, tan x and x are equal to first order.
- Ray vector ( y , n alpha ): height above the axis and optical direction, n times the slope in radians; slope positive when the ray rises.
- Power of a surface P = (n2 - n1)/R (dioptre when R is in metres); power of a system P = -C; equivalent focal length F = -1/C in air.
- System matrix: the product M = M_N ... M_2 M_1 of translation and refraction matrices, first event rightmost; determinant 1 in the (y, n alpha) form.
- Principal (unit) planes: conjugate planes of magnification +1; the thick system acts as a thin lens placed at them. Nodal points: conjugate axial points of angular magnification +1.
- Cardinal points: two focal points, two principal points and two nodal points (Brij Lal PDF p. 109).
- Vocabulary: vertex is where a surface meets the axis; refraction matrix and translation matrix are the two building blocks; principal (unit) planes and cardinal points let a thick system act as a thin lens (module 7); Gauss constants are the book's name for the four matrix entries.

### Notes: Equations to know

- Translation: T = [ 1 d/n ; 0 1 ]. Refraction: R = [ 1 0 ; -P 1 ], P = (n2 - n1)/R. Both have determinant 1.
- System matrix in air: y_out = A y_in + B (n alpha)_in, (n alpha)_out = C y_in + D (n alpha)_in, AD - BC = 1.
- F = -1/C; alpha = (D - 1)/C from the first vertex; beta = (1 - A)/C from the last vertex; back focal distance F A, front focal distance -F D.
- Imaging (object s to the left of V1, image v to the right of V2): v = -(A s + B)/(C s + D), m = 1/(C s + D); B_total = 0.
- Thin lens: M = [ 1 0 ; -(P1 + P2) 1 ], 1/f = (mu - 1)(1/R1 - 1/R2), 1/v - 1/u = 1/f.
- Thick lens: A = 1 - P1 t/mu, B = t/mu, C = -(P1 + P2 - P1 P2 t/mu), D = 1 - P2 t/mu; 1/F = (mu - 1)[1/R1 - 1/R2 + (mu - 1) t/(mu R1 R2)].
- Two thin lenses: 1/F = (f1 + f2 - d)/(f1 f2); alpha = F d/f2 (from lens 1); beta = -F d/f1 (from lens 2).
- Different media: f1 = -n1/P, f2 = n2/P; H1 at n1 (D - 1)/C, H2 at n2 (1 - A)/C; N1 at (n1 D - n2)/C, N2 at (n1 - n2 A)/C; (y, alpha) form has determinant n1/n2.
- Gauss formula from the principal planes: 1/v - 1/u = 1/F.

### Notes: Book convention to this lesson's convention

- Brij Lal Chapter 7 writes the ray as ( lambda , x ) with lambda = mu alpha; this lesson writes ( y , n alpha ). The same physics, different bookkeeping.

### Notes: Derivation skeletons

- Refraction matrix: i = alpha1 + y/R, r = alpha2 + y/R; n1 i = n2 r gives n2 alpha2 = n1 alpha1 - ((n2 - n1)/R) y; y unchanged.
- Imaging: T(v) M T(s) has B entry A s + B + v (C s + D); set to zero; magnification A_total = A + vC = 1/(C s + D) from the determinant.
- Thick lens: T R1 = [ 1 - P1 t/mu, t/mu ; -P1, 1 ]; left-multiply by R2; read A, B, C, D; verify AD - BC = 1.
- Principal planes: M = T(-beta) L T(alpha) with L = [ 1 0 ; -1/F 1 ] gives C = -1/F, A = 1 + beta/F, D = 1 - alpha/F.
- Two thin lenses: M = L2 T(d) L1; C = -(1/f1 + 1/f2 - d/(f1 f2)); alpha = F d/f2; beta = -F d/f1.

### Notes: Limiting cases and checks

- t -> 0 in the thick lens gives the thin lens; d -> 0 in the two-lens matrix gives the sum of powers.
- d = f1 + f2 gives C = 0 (afocal telescope); d > f1 + f2 gives F < 0.
- A plane surface has P = 0 and R = identity; a single air-glass surface has both principal planes at the vertex and both nodal points at the centre of curvature.
- Principal planes may be crossed or lie outside the instrument; positive F does not guarantee a real back focus (2024 numerical: F = +40 cm but F2 is 60 cm to the left of lens 2).
- Every product must have determinant 1 in the (y, n alpha) form: a failure signals an arithmetic error or a wrong sign of P2.

### Notes: Confused concepts

- Focal length is measured from a principal plane, not from a lens vertex (except for a thin lens).
- alpha is measured from the first vertex and beta from the last vertex, both positive to the right.
- The product order is the reverse of the order in which light meets the elements.
- Power P = -C (diopter) is not the same as the surface power P1 or P2.
- Principal planes (unit linear magnification) are not the nodal points (unit angular magnification); they coincide only when the media at the ends are the same.
- Paraxial (first-order) optics gives no aberrations; the exact ray trace differs, as the spherical-aberration table in module 2 shows.

### Core concepts

- A paraxial ray is described by (y, n alpha); each step is a 2x2 matrix, so a whole system is one matrix [A B; C D] with determinant 1.
- C = -1/F gives the focal length; B = 0 is the imaging condition; A is the lateral magnification and D = 1/A there.
- The product order is the reverse of the order of the elements: M = M_N ... M_1.
- Principal planes lie at alpha = (D - 1)/C and beta = (1 - A)/C; measured from them 1/v - 1/u = 1/F.
- Thin lens P = P1 + P2; thick lens adds -P1 P2 t/mu; two lenses 1/F = 1/f1 + 1/f2 - d/(f1 f2).

- Paraxial ray: sin x ≈ tan x ≈ x; ray vector (y, nα), rising ray positive
- Building blocks: translation T = [1 d/n; 0 1], refraction R = [1 0; −P 1], P = (n₂ − n₁)/R, both determinant 1
- System matrix M = M_N … M₁ (first element rightmost): F = −1/C, B = 0 for imaging, AD − BC = 1
- Thin lens: C = −(P₁ + P₂), lens formula 1/v − 1/u = 1/f (2017)
- Thick lens: T(t/μ) between R₁ and R₂; t → 0 gives the thin lens (2022, 2025)
- Principal planes α = (D − 1)/C from the first vertex, β = (1 − A)/C from the last; nodal points
- Two thin lenses: 1/F = 1/f₁ + 1/f₂ − d/(f₁f₂), α = Fd/f₂, β = −Fd/f₁ (2024)
