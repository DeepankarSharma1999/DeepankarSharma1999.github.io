## PH-086: RMS and average AC values

Physics Paper I · Physics · Current electricity

*Goal:* Understand RMS and average AC values, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

RMS and average AC values belongs to Current electricity. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Label currents and polarities before writing Kirchhoff equations. For transients find initial and final conditions plus the time constant; for sinusoidal steady state use complex impedance and report measurable RMS values. Resonance and bandwidth must use the same circuit convention.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing rms and average ac values. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: In a linear lumped circuit illustrating rms and average ac values, write all governing relations and solve for the requested current/voltage ratio.
