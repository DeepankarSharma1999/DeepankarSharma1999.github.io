## PH-204: Thermistors

Physics Paper II · Physics · Devices and electronics

*Goal:* Understand Thermistors, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Thermistors belongs to Devices and electronics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Start from the device characteristic and operating region, then build the circuit relation. Mark bias polarity, current direction and reference ground. For logic, write the truth table before simplifying; for amplifiers distinguish voltage gain, power gain, feedback and saturation.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing thermistors. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: Draw a circuit/energy-band/truth-table model for thermistors; find output for one appropriate input condition.

### Worked example

Worked route: identify the requested result in “Derive the main physical relation(s) governing thermistors. Define every symbol, state approximations and provide a labelled sketch where useful.”; select the governing principle; state assumptions; carry the algebra without skipping vector directions or boundary conditions; then interpret the result physically. Use the supplied self-check rubric: Assessment: principle and diagram → algebra/derivation → assumptions → units/limiting case.
