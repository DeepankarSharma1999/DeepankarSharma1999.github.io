## PH-095: Scalar and vector potentials

Physics Paper I · Physics · EM waves and radiation

*Goal:* Understand Scalar and vector potentials, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Scalar and vector potentials belongs to EM waves and radiation. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Start from Maxwell’s equations and the material relations. For a plane wave verify E, B and propagation direction, then use the Poynting vector for energy flow. At an interface apply tangential boundary conditions; for radiation laws state the variable and integration range.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing scalar and vector potentials. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: For plane wave fields or a radiating body, formulate an observable for scalar and vector potentials and show the relevant low/high-frequency limit.
