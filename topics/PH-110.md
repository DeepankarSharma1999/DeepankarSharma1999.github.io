## PH-110: Gibbs phase rule

Physics Paper I · Physics · Thermodynamics

*Goal:* Understand Gibbs phase rule, set up its governing relations, and complete one UPSC-style derivation or application.

### What to learn

Gibbs phase rule belongs to Thermodynamics. Build the topic around definitions, the governing equation, assumptions, and one physical interpretation. Define the system, path and sign convention. Use dU=δQ−δW while remembering that heat and work are path quantities. Entropy, free energy and Maxwell relations require the relevant constraints; check reversible limits before applying ideal-gas shortcuts.

### How to practise it

Use this exact checkpoint: Derive the main physical relation(s) governing gibbs phase rule. Define every symbol, state approximations and provide a labelled sketch where useful. Work line by line: list the givens or starting law, draw the geometry where useful, derive symbolically, then substitute numbers. End with units, sign, scale and a limiting-case check. After that attempt the second application without notes: In a quasi-static process involving gibbs phase rule, determine signs and expressions for Q, W, ΔU or ΔS; state constraints.
